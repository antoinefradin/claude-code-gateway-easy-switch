Switch Claude Code's gateway in one command.

ccgs flips Claude Code between the native Anthropic API and any LiteLLM or OpenAI-compatible proxy — without ever hand-editing settings.json. Only its four keys move; everything else stays untouched.

Install ccgs Source
  • Pure Bash 3.2+Runs on stock macOS shell and any Linux. No Node, no compiled binary.
  • Zero settings corruptionOnly four ANTHROPIC_* keys move. Theme, hooks, permissions untouched.
  • Atomic writes + backupsEvery change is written atomically and the last 10 settings.json are kept.
  • MIT licensedOne readable script. Nothing runs that you can't audit in the repo.

The cost

Every gateway switch is a hand-edit waiting to break.

To point Claude Code at a proxy you open ~/.claude/settings.json, add the right env keys, get the quoting right, and hope you didn't clobber your theme or hooks. Switch back and you undo it all by hand. Do it a few times a day and one of those edits eventually corrupts the file.

4 manual edits · 1 fragile file

  1. opensettings.json→edit env blockmind the trailing comma
  2. pasteBASE_URL + TOKEN→4 keys by handtoken in shell history
  3. setANTHROPIC_MODEL→which id again?no model list
  4. switchback to native→delete keys by handstale API key shadows token

One bad edit and the whole file stops parsing.

Commands

One verb per intent. JSON and tables, never guesswork.

Add a proxy once, then switch with a single word. ccgs reads model lists straight from the gateway and lets you pick a default with the arrow keys.

Full reference
~/.claude/settings.json

Flip Claude Code to a named proxy, then back to native. ccgs rewrites only its own keys.

$ ccgs proxy litellm
[ccgs] Switched to proxy 'litellm'.
  URL:   https://litellm.my-company.com
  Key:   sk-mykey...
  Restart Claude Code to apply.

$ ccgs native
[ccgs] Switched to native Anthropic mode.
  Proxy settings cleared from settings.json.

Register a proxy once — positional or named flags. No-auth proxies are fine too.

$ ccgs add litellm https://litellm.my-company.com sk-mykey
[ccgs] Proxy 'litellm' configured.
  URL:  https://litellm.my-company.com
  Key:  sk-mykey...

  Switch to it:          ccgs proxy litellm
  List models:           ccgs models list litellm
  Set a default model:   ccgs models set litellm

List models straight from the gateway, or pick a default interactively with the arrow keys.

$ ccgs models list litellm

How it works

It edits four keys, and only ever those four.

ccgs stores your proxies in its own XDG config and projects them into the env block Claude Code already reads. No daemon, no cloud account, no wrapper around the CLI.

  • Only four managed keys

    ANTHROPIC_BASE_URL, ANTHROPIC_AUTH_TOKEN, ANTHROPIC_API_KEY and ANTHROPIC_MODEL are the only keys ccgs touches. Theme, effortLevel, permissions, hooks and every other env var pass through untouched.

    ~/.claude/settings.json

  • Multiple named proxies

    Keep LiteLLM, OpenRouter, an internal gateway and open no-auth proxies side by side. Switch between any of them by name in one command.

    ccgs add · ccgs list

  • Interactive model picker

    Fetch the model list live from the proxy's /v1/models and choose a default with the arrow keys. Piped input falls back to a numbered prompt for CI.

    ccgs models set litellm

  • Session mode

    Apply a switch to only the current shell — exported as env vars instead of written to settings.json — so one terminal can use a proxy while the rest stay native.

    ccgs proxy litellm --session

  • Atomic writes & backups

    settings.json is rewritten via a temp file and os.replace, never edited in place, and the last ten versions are kept so a bad switch is always recoverable.

    tempfile + os.replace

  • Clean by construction

    Empty key or model values are omitted entirely, ANTHROPIC_API_KEY is only ever cleared so a stale key can't shadow the token, and ccgs never adopts settings it didn't write.

    ccgs native

Install

One line, then it's on your PATH.

The script installs ccgs to ~/.local/bin and injects a shell function into your .zshrc or .bashrc. Choose --user, --system, or --project.

Install guide Clone & build 
$ curl -fsSL https://raw.githubusercontent.com/antoinefradin/\
      claude-code-gateway-easy-switch/main/quick-install.sh | bash
 
✓ ccgs installed in ~/.local/bin
✓ shell function added to ~/.zshrc
 
# then add a proxy and switch
$ ccgs add litellm https://litellm.my-company.com sk-key
$ ccgs proxy litellm
